claude-code-deepseek

在 Claude Code 里使用 DeepSeek API

从注册账号、充值，到把配置文件放进正确的目录、跑通第一次对话。下面按操作系统分栏，先选你的系统，全站步骤会自动跟着切换。

操作系统

0安装 Claude Code

需要 Node.js 18 或更高版本。推荐用官方安装脚本：

curl -fsSL https://claude.ai/install.sh | bash

或者用 npm 全局安装：

npm install -g @anthropic-ai/claude-code

验证是否装好：

claude --version

4把配置放到正确的目录

这是最容易出错的一步。Claude Code 会从多个位置读取 settings.json，放错地方就会出现「明明配了却不生效」。

有效的路径有哪些

位置macOS 路径生效范围
用户级 ⭐~/.claude/settings.json这台机器上你的所有项目
项目共享<项目>/.claude/settings.json该项目所有人（会提交 git）
项目本地<项目>/.claude/settings.local.json仅你自己，不进 git

优先级（高 → 低）

1managed-settings.json托管策略
2claude --settings命令行
3.claude/settings.local.json当前项目 · 仅你
4.claude/settings.json当前项目 · 共享
5~/.claude/settings.json全局 · 优先级最低

同一个配置项在上层文件里也写了，下层文件里的会被覆盖。比如当前项目里有 .claude/settings.local.json，它会盖掉你写在用户级的配置。

动手操作

# 1. 确认目录存在（装完 Claude Code 通常已经有了）
mkdir -p ~/.claude

# 2. 备份已有配置（如果之前配过）
cp ~/.claude/settings.json ~/.claude/settings.json.bak 2>/dev/null

# 3. 把仓库里的模板复制过去并改名
cp settings_example.json ~/.claude/settings.json

# 4. 打开编辑器，把 your_deepseek_api_key_here 换成你自己的 Key
open -e ~/.claude/settings.json

在 Finder 里想看到 ~/.claude 这个隐藏目录：按 ⌘ + ⇧ + G，输入 ~/.claude 回车。

0安装 Claude Code

Windows 推荐用原生 PowerShell 安装，比 WSL 省事：

irm https://claude.ai/install.ps1 | iex

安装完 claude 会加入 PATH，关掉当前 PowerShell 再开一个新的，然后验证：

claude --version

如果你用的是 WSL2：请切到上面的「Linux / WSL」标签页。WSL 里跑 Claude Code，配置要走 WSL 内部的 Linux 家目录，和 Windows 的 C:\Users\... 是两套完全独立的文件系统，放错了必然不生效。

这是最容易出错的一步。Claude Code 会从多个位置读取 settings.json，放错地方就会出现「明明配了却不生效」。

有效的路径有哪些

位置Windows 路径生效范围
用户级 ⭐%USERPROFILE%\.claude\settings.json
即 C:\Users\你的用户名\.claude\settings.json		这台机器上你的所有项目
项目共享<项目>\.claude\settings.json该项目所有人（会提交 git）
项目本地<项目>\.claude\settings.local.json仅你自己，不进 git

优先级（高 → 低）

1managed-settings.json托管策略
2claude --settings命令行
3.claude\settings.local.json当前项目 · 仅你
4.claude\settings.json当前项目 · 共享
5%USERPROFILE%\.claude\settings.json全局 · 优先级最低

同一个配置项在上层文件里也写了，下层文件里的会被覆盖。比如当前项目里有 .claude\settings.local.json，它会盖掉你写在用户级的配置。

动手操作（PowerShell）

# 1. 确认目录存在
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.claude"

# 2. 备份已有配置
if (Test-Path "$env:USERPROFILE\.claude\settings.json") {
    Copy-Item "$env:USERPROFILE\.claude\settings.json" "$env:USERPROFILE\.claude\settings.json.bak"
}

# 3. 把仓库里的模板复制过去并改名（先 cd 到本仓库目录）
Copy-Item ".\settings_example.json" "$env:USERPROFILE\.claude\settings.json"

# 4. 用记事本打开，替换 Key
notepad "$env:USERPROFILE\.claude\settings.json"

记事本保存时注意两件事：

  • 编码选择 UTF-8
  • 别把文件存成了 settings.json.txt——在资源管理器「查看」里勾上「文件扩展名」，就能看清真实后缀

想快速进到那个目录：在文件资源管理器地址栏直接输入 %USERPROFILE%\.claude 回车。

1注册 DeepSeek 开放平台

  1. 打开 platform.deepseek.com
  2. 点右上角 Sign up / 注册，用邮箱或手机号注册
  3. 完成邮箱 / 短信验证，登录进控制台

别搞混两个站点：chat.deepseek.com 是网页版聊天，不提供 API Key；platform.deepseek.com 才是开放平台，API Key 和充值都在这里。

2实名认证与充值

DeepSeek 的 API 是预付费模式：先往账户余额里充钱，再按实际消耗的 Token 从余额扣除。余额为 0 时，即使 Key 是有效的，请求也会返回 402 Payment Required。

  1. 实名认证（如平台提示需要）：右上角头像 → 账户设置 → 实名认证。个人上传身份证，企业上传营业执照，审核通过后状态显示「已通过」。
  2. 充值：右上角头像 → 账户余额 / 充值中心。支持支付宝、微信支付、对公银行转账。最低金额与到账时间以页面实时显示为准。
  3. 充值到账后回到 API Keys 页面，Key 的状态会变成「可用」。

新账号可能有赠送额度，但不要依赖老教程里的具体数字，以你自己的账单页为准。

3创建 API Key

  1. 登录开放平台，左侧导航进入 API Keys：platform.deepseek.com/api_keys
  2. 点 Create new API key
  3. 起个名字，建议「用途_环境」格式，例如 claude-code-mac、claude-code-win
  4. 立刻复制弹出的 Key——它只在弹窗里显示这一次，关掉后平台不再提供明文，只能删掉重建

Key 的格式形如 sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx。

给不同设备 / 用途分别建 Key，方便单独吊销和统计用量。泄露了直接在同一页面删除即可。

{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "your_deepseek_api_key_here",
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_DEFAULT_FABLE_MODEL": "deepseek-v4-pro[1M]",
    "ANTHROPIC_DEFAULT_FABLE_MODEL_NAME": "deepseek-v4-pro",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-v4-flash",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro[1M]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL_NAME": "deepseek-v4-pro",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-v4-pro[1M]",
    "ANTHROPIC_DEFAULT_SONNET_MODEL_NAME": "deepseek-v4-pro",
    "ANTHROPIC_MODEL": "deepseek-v4-pro",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": 1,
    "API_TIMEOUT_MS": "3000000"
  },
  "includeCoAuthoredBy": false,
  "model": "haiku",
  "effortLevel": "medium"
}
键作用
ANTHROPIC_AUTH_TOKEN你要改的就是这个。填 DeepSeek 的 API Key，Claude Code 会自动加上 Bearer 前缀
ANTHROPIC_BASE_URL把请求指向 DeepSeek 的 Anthropic 兼容端点，而不是 Anthropic 官方
ANTHROPIC_DEFAULT_
OPUS / SONNET / HAIKU_MODEL		分别定义 opus / sonnet / haiku 三个别名实际指向哪个 DeepSeek 模型
..._MODEL_NAME界面上显示的名字，纯显示用
ANTHROPIC_MODEL默认使用的模型
CLAUDE_CODE_DISABLE_
NONESSENTIAL_TRAFFIC		关掉自动更新、遥测、错误上报等非必要网络请求（走第三方接口时的推荐做法）
API_TIMEOUT_MS请求超时（毫秒）。这里设得宽松，避免长回答被提前掐断
model默认档位。haiku 即默认走 deepseek-v4-flash（便宜）。想默认用 pro 就改成 "opus" 或 "sonnet"
includeCoAuthoredBy是否在 git 提交信息里加 Co-Authored-By 署名
effortLevel思考 / 努力程度档位

?常见问题

配好了但完全没生效，还是连的 Anthropic 官方？
  1. 文件名是不是叫 settings.json（不是 settings_example.json，也不是 settings.json.txt）
  2. 路径对不对：macOS 是 ~/.claude/settings.json，Windows 是 %USERPROFILE%\.claude\settings.json
  3. JSON 格式是否合法——多一个逗号整个文件就会失效。用 python3 -m json.tool ~/.claude/settings.json 校验
  4. 是不是被更上层的配置覆盖了，检查当前项目的 .claude/settings.json 和 .claude/settings.local.json
  5. 重启 Claude Code
环境变量和 settings.json 冲突时听谁的？

对 ANTHROPIC_MODEL 这类变量，Claude Code 先读环境变量，环境变量没设时才用 settings.json 里的 model 值。而 --model 命令行参数和 /model 命令的优先级又高于 ANTHROPIC_MODEL。如果你之前手动 export 过 ANTHROPIC_*，记得先清掉。

想临时切回官方 Claude 模型怎么办？

把 ~/.claude/settings.json 改名备份（例如 settings.json.deepseek），需要时再改回来。更干净的做法是：不放用户级，只放在具体项目的 .claude/settings.local.json 里。

Windows 上装完 claude 命令找不到？

关掉当前终端窗口重开一个，让 PATH 刷新。如果还不行，检查 %USERPROFILE%\.local\bin 是否在 PATH 中。

API Key 安全方面要注意什么？
  • API Key 等同于账号密码：不要提交到 Git、不要贴在截图里、不要发到群里
  • 仓库里的 settings_example.json 放的是占位符，保持它是占位符再提交
  • 想共享配置给团队：把 Key 改成读环境变量，或只写到 .claude/settings.local.json（Claude Code 会自动把它加进全局 gitignore）
  • Key 泄露了立即去 API Keys 页面删除并重建
